    How it stays private

    1. Your browser hashes the password with SHA-1 using the built-in Web Crypto API.
    2. Only the first 5 characters of the hash go to the Have I Been Pwned API. Hundreds of different passwords share every prefix, so the API can't tell which one you typed.
    3. The API returns every leaked hash suffix that starts with those 5 characters, padded with fake rows so even the response size reveals nothing.
    4. Your browser looks for the remaining 35 characters in that list. The match happens here, on your device.

    This technique is called k-anonymity. It's the same method used by password managers and browsers to warn you about leaked passwords. The source code is public so you can check it yourself.
